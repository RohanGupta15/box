# Box logo: usage guide

**Idea:** a soft keepsake jar whose lid seam and slot make a quiet smile. The lid says "private", the smile says "friendly".

## Files (`final/`)
| Use | File |
|---|---|
| Master symbol | `keepsake.svg` |
| Toolbar / favicon (16-32 px) | `keepsake-small.svg`, `favicon.svg`, `favicon.ico` |
| Horizontal lockup | `keepsake-horizontal.svg` (+ `-black`, `-white`, `-mono-2f5d57`) |
| Stacked lockup | `keepsake-stacked.svg` (+ variants) |
| App icon tile | `keepsake-app-icon.svg`, `icon-192.png`, `icon-512.png`, `maskable-512.png` |
| Wordmark only | `wordmark.svg` |

## Colour
| Name | HEX | RGB | Use |
|---|---|---|---|
| Keepsake teal | `#2F5D57` | 47 93 87 | Mark, icon tile, accents |
| Mist | `#F3F5F2` | 243 245 242 | Mark on teal, light backgrounds |
| Ink | `#18181B` | 24 24 27 | One-colour black version |

Teal on Mist is 6.8:1 contrast. Also approved: black or white one-colour versions on any plain background.

## Clear space and size
- Clear space on every side: the height of the lid gap x 4 (about 1/4 of the symbol height).
- Below 32 px use `keepsake-small.svg` (wider lid gap, thicker smile). Minimum 16 px.
- Horizontal lockup minimum width: 96 px.

## Don't
- Recolour the lid and body differently, or add gradients or shadows.
- Close the lid gap or turn the smile into a frown or a different face.
- Stretch, rotate, or set the wordmark in another font.
- Place the mark on busy photos without a solid tile.

## Notes
- The wordmark is built from geometric paths; no font licence is needed.
- No trademark search has been done. Run one before any public release.
